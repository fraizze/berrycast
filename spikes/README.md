# spikes/

Prototypes **jetables** des tests de faisabilité (étapes 02 à 04) :

- le Pi apparaît-il dans Windows + K ? (Wi-Fi Direct)
- Windows accepte-t-il de diffuser vers le Pi ? (négociation RTSP)
- le Pi affiche-t-il la vidéo de façon fluide ? (GStreamer)

Ce code n'est pas destiné à la production : il sert à vérifier qu'une piste fonctionne avant
d'écrire le vrai code dans `berrycast/`.
